# ⏳ Hourglass

**Every scroll has a price. See what you could build instead — one minute at a time.**

Hourglass is a small, gamified web app that turns your screen time into a mirror. Track how many minutes you spend on your phone, tablet, or computer — via a live timer or manual entry — and instantly see what those same minutes could have become: pages read, kilometers walked, push-ups done, words journaled, or a call to someone you love.

🔗 **Try it live:** [dim00dim.github.io/Hourglass](https://dim00dim.github.io/Hourglass/)

---

## ✨ Features

- **Live timer** with an animated hourglass ring that fills as time passes
- **Manual entry mode** for logging time you've already spent
- **Instant conversions** into real, concrete alternatives — no vague advice, just numbers
- **Mindful minutes & day streak** tracked locally to encourage daily awareness
- **Bilingual** — auto-detects your browser language (Italian / English), switchable anytime
- **100% private** — no account, no server, no tracking. All data stays in your browser

## 🛠️ Built with

Plain **HTML, CSS, and JavaScript** — no frameworks, no build step. Open `index.html` and it just works.

## 🚀 Run it locally

1. Clone or download this repository
2. Open `index.html` in any browser

That's it — no installation required.

## 📁 Project structure

```
hourglass/
├── index.html   → structure and content
├── style.css    → design system and animations
└── script.js    → timer, conversions, i18n, and local storage logic
```

## 💡 Why

Screen time trackers usually just show you a number. Hourglass goes one step further: it makes that number *mean something*, one small, human-sized alternative at a time.
